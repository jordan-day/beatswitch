# Sample credits

All recorded sounds in this folder come from the **Versilian Community Sample Library (VCSL)**
by Versilian Studios LLC — https://github.com/sgossner/VCSL — released under
**CC0 1.0 (public domain)**: "you can do whatever you want with these sounds ... no royalties,
no credit, no special terms." Credited here anyway, with thanks.

They were trimmed, faded, converted to mono 22.05 kHz 16-bit WAV, normalized, and tuned to exact
semitones by `scripts/process-samples.mjs`. The original files are listed in `scripts/vcsl-files.txt`.

| Folder | Instrument (VCSL) | Notes / sounds |
| --- | --- | --- |
| `kit/` | Bass Drum 1, Snare Drum Modern 1, Hi-Hat Cymbal, Claps, Shaker (Small), Tambourine 1 | kick, snare, hat, openhat, clap, shaker, tambourine |
| `piano/` | Upright Piano, Knight (soft layer) | A2, F3, C#4, A4, F5, C#6, A6 |
| `vibes/` | Vibraphone, soft mallets | F3, C4, G4, D5, A5, E6 |
| `kalimba/` | Kalimba, Kenya | B3, D#4, G#4, C#5, F#5, B5 |
| `glock/` | Glockenspiel, soft | G5, C6, G6, C7, G7 |
| `ocarina/` | Ocarina, Typical (sustain) | A4, C#5, E5, G#5, C#6 |

Note names follow the usual convention (middle C = C4); VCSL's file names use middle C = C3.
